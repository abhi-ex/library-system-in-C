# Library System

This project is a small C-based library management application.

## Features
- Add books to the library
- Search by ISBN, title, or author
- View all currently stored books
- Remove a book by ISBN
- Exit cleanly from the menu system

## Build
```bash
gcc -std=c11 -Wall -Wextra -O2 libraray.c -o libraray.exe
```

## Run
```bash
./libraray.exe
```
